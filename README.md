# Harish Challa — GitHub Pages Portfolio

Personal portfolio for Harish Challa.

## Local preview

Open `index.html` in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

This is designed for the user-site repository:

`harishchalla-cloud.github.io`

Push the files to the `main` branch and enable GitHub Pages from repository settings if it is not already enabled.

## Structure

```text
.
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── profile.jpg
    └── Harish_Challa_Resume.pdf
```

## Before publishing

Review the public project repositories and remove any secrets, credentials, `.env` files, private keys or other sensitive material before linking them from the portfolio.
